## そのまま置いています

これらは**手を入れていない内部の作業文書**です。読みやすく書き直していません。

- **版の履歴・出典の札・「まだ確かめていない」の印・「誰の返事待ちか」**が残っています。
  それ自体が、どう辿り着いたかの記録だからです。
- **フォルダ名やファイル名は、公開されていない場所**を指します。辿れません。
- `★` は内部で使っている強調の印です。
- `[一次確認]` `[2次一致]` `[未確認]` は**根拠の強さの札**です。
  自分で原文に到達したものだけが `[一次確認]` です。

読みにくいはずです。**読みやすく直すと、札と版が落ちます。** 落とさないほうを選びました。
