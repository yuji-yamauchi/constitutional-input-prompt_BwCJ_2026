# 08_sources — 確かめた跡の置き場

この器は、**法令の条文を、原文のまま出す**と言っています。
言うだけなら誰でも言えるので、**確かめた跡をここに置きます。**

英語版は [`../en/`](../en/) にあります。

---

## ここに置くもの

- **法令の写しと、原文との突合の報告**
- 調査の報告（何を調べ、どこに到達し、何が分かって、何が分からなかったか）

## 書き方の決まり

1. **到達した場所を書く。** 「調べました」ではなく、「どこの、いつの版に、どうやって届いたか」。
2. **確かさを 3 つに分ける。**
   - **一次確認** — 原文に自分で到達して、逐語で写した
   - **二次一致** — 解説や報道で一致したが、原文には届いていない
   - **未確認** — 届いていない
3. **「無い」と書かない。** 書けるのは「**探した範囲には無い**」まで。同じ行に、どこを探したかを書く。
4. **数を出すときは、数え方を同じ行に書く。** 書けない数は出さない。
5. **分からなかったことを削らない。** 削ると、報告が「できたことの一覧」になります。
