# 08_sources — Where the checking is written down ／ 確かめた跡の置き場

Reports of what was looked up, where it was reached, and what was found —
statutes above all. Put here so that a claim in this repository can be
followed back to the place it came from.

調べた物・どこに到達したか・何が分かったかの報告。とくに法令。
この repo に書いてあることを、**出てきた場所まで辿れるように**するための置き場です。
