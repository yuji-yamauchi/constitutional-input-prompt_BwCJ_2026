# 06_ecosystem — 受け口の先に居る人と道具

この器が届くのは、本人と、本人が渡すと決めた相手までです。
その先に何が要るのか、誰が担うのか——**今回つくらないが、考えたことを残します。**

英語版は [`../en/`](../en/) にあります。

---

## 1. この器が約束できる範囲

先に、できないことを書きます。

| 層 | 誰の仕事か | 何ができるか |
|---|---|---|
| **一人ひとり** | 事業所・支援者（＝私たちの仕事） | **見えるようにするところまで** |
| **社会保障（制度）** | 合意された法と制度 | **引き受けること（＝費用を制度が持つ）** |

**事業所にできるのは、可視化だけです。計上は、返済ではありません。**

帳簿に載せたからといって、誰かの負担が減るわけではない。
負担を実際に引き受けるのは制度の層で、それは政治の層です。
だから、**一事業所が「これで解決する」とは言いません。**

## 2. 公衆衛生として読む

この器の背景には、社会の基盤の脆さを読むための、**三つの独立した見方**があります。

| | 何を指すか |
|---|---|
| **アノミー** | 規範の弛緩、社会的な絆からの離脱。**失うものが無い状態が、社会の予測可能性を壊す** |
| **ヒュブリス** | 力を持つ側の過剰と驕り。**権力が、自らへの点検を免れる** |
| **ヒュノプス** | 諦め・沈黙・認知の麻痺。**自分についての定義を、他人から受け取り続けること** |

### 読み方の規律

- **三つは独立しています。** 対にしません。
- **順番に並べません。** 「アノミーの次にヒュブリスが来る」といった段階として扱いません。
- **抵抗を病気にしません。** 異議申し立て・苦情・内部通報を、アノミーの例として説明しません。

### なぜ「公衆衛生」なのか

**コレラを、個人の不摂生のせいにせず、水道を直す。** 同じ構造です。

「あの人が弱いから」「あの人が驕っているから」ではなく、
**どういう条件が、その状態を量産しているか**を見る。これが脱・個人化です。

## 3. 順序を、逆立ちさせない

> 人権を保障するほうが、社会の基盤は強くなる。

これは正しく、そして**強力な政治的論証**です。
**しかし、これを人権の根拠にはしません。**

根拠は尊厳です。基盤が強くなることは、制度化を支える論証であって、**結果**です。

**理由は単純です。** 根拠にしてしまうと、
「ある集団の権利を削るほうが、基盤は強くなる」というデータが出た日に、
**同じ論法が、権利の侵害を許可してしまう**からです。

費用の話も同じです。この器の `03_monetization` が 03 にあって 00 にないのは、そのためです。

---

## 4. なぜ、意思決定支援は足りないのか

ここが、いちばん底にある構造です。

**本人が自分で決めること**は、変わった形をした財です。

- **便益は、本人に落ちます。**
- **負担は、周囲のそれぞれに落ちます。** 家族にも、医療にも、福祉にも、行政にも。

それぞれが自分の負担を小さくしようとすると、どうなるか。

> **全員のそれぞれにとって最適な状態が、「本人が決めないこと」に収束します。**

誰も悪意を持っていません。それでもそうなります。
**誰も報われないから、誰も供給しない。** 受け取るはずの人が、いちばん力を持たない。

帳簿の言葉で置くと、こうなります。

> **この仕組みの「効率」とは、本人にどれだけ押し付けたかの度合いです。**

周りは自分の帳簿を軽くし、費用は、断れない人の**計上されない元帳**に積まれます。
抑えられた意思、言葉にならなかった負荷、縮んだ自己。

## 5. 社会インパクトを、どう数えるか

ここが、この器の設計に直結します。

### 摩擦のなさを、成果にしない

**苦情ゼロ。全員が指示どおり。高い定着率。**

——これは、**いちばん抑圧的な状態でもありえます。**
何も言わないのは、満足しているからかもしれないし、言っても無駄だと学んだからかもしれない。
**その二つは、同じ数字に見えます。**

### だから、逆を数える

| 数えるもの | 何の信号か |
|---|---|
| **記録が訂正された回数** | 本人が「違う」と言えた |
| **拒否された回数** | 断る余地があった |
| **異議が記録された回数** | 言い分が残る場所があった |
| **離脱した回数** | 出ていく自由があった |
| **同意しなかった回数** | 同意が形式でなかった |

**摩擦は失敗ではありません。抑圧の均衡が破れている証拠です。**

この器が、点数も順位も判定も返さないのは、ここから来ています。
返した瞬間に、測るものが「本人の状態」に戻ってしまう。
**数えてよいのは、本人が何をできたかであって、本人がどうであるかではありません。**

## 6. そして、刃はこちらを向く

**この器を作っている事業所も、第 4 節の「周囲」の一人です。**

定着率に連動する報酬は、構造として、
**決めない・置かれたまま残る・手のかからない利用者**を欲しがります。

だから、違いは「良い意図」ではありません。

> **違いは、自分の押し付けを、自分の利益に逆らって計上することです。**

善意に頼る設計は、善意が切れた日に壊れます。
だからこの器は、**善意が無くても同じように動く形**で作られています。
ここを外せば、この器は**五番目の押し付け先**になります。

## 7. 15 年前の図と、そこから残したもの

この構想の原型は、**約 15 年前に書かれた 1 枚の図**です。

その図では、個人の健康情報を**共有財**として基盤に預け、
運用益が「**自分の基盤を無料で使える権利**」として本人に返る、という循環が描かれていました。
預け先は研究・民間・行政の三方向で、運用者には品質の保証が求められる。

**いま、その形はそのまま採りません。** 理由は 4 つあります。

| | なぜ |
|---|---|
| **匿名という前提** | 当時は「匿名にすれば使える」が通った。いまは**再識別される前提**で設計する |
| **鶏と卵** | 返ってくるものが「基盤の無料利用」である以上、**最初の人には返すものが無い** |
| **回収の実績** | この種の基盤事業は、国内でほとんど生き残っていない。**矢印は描けても、金が流れた証拠が要る** |
| **「投資」という言い方** | 力の差がある場で「投資を募る」と言うと、**主語が運用者の側に戻ります** |

### 残したものは、一点だけです

> **払えない人にも、基盤が届くこと。**

この一点が、15 年前の図がいまも答えている問いです。
変えたのは、**その届け方**です。

## 8. 誰に、何を担ってほしいか

この器は、モデルを自前で持ちません。聞き役は外部のモデルです。
だから、この器が届く範囲は、**そのモデルに届けるかどうか**に左右されます。

### お願いしたいこと

**(1) 到達そのもの**

障害のある人が、**プロンプトを打てるところまでのリソース**。
それだけです。

**データとの交換ではありません。**
「無料で使える代わりに、障害名や特性を学習に使わせてほしい」という形は、
一見すると誰も損をしませんが、**本人の記録を対価にした時点で、記録は値段の人質になります。**
払えない人ほど差し出す構造になる。だから、**交換条件にせず、到達だけをお願いします。**

渡すかどうかは、そのあとで本人が別に決めることです。

**(2) 「判定を返さない」を、モデルの側でも**

この器は、入力の段で守っています——本人が書いた文を、そのまま返す。書き換えない。
ですが、**出力の段で守れるのは、モデルを持っている側だけ**です。

- 人の性格や特性を推し量って返さない
- 「この人はこういう人です」という形の答えを作らない
- 聞かれていない判断を足さない

**この 3 つは、わたしたちの側では完全には守れません。**

**(3) 届いたあとに、何が起きたかを見られること**

無償で配るだけでは、第 5 節の「摩擦のなさ」と同じ罠にかかります。
**配った数ではなく、本人が何をできたかを数える**——その設計に、一緒に関わってほしい。

### 言えないこと

これは**要望であって、合意ではありません。**
誰かと話がついている事実はありませんし、この文書に書いたことで何かが決まるわけでもありません。
**あるべき形として書いています。**

## 9. この文書の限界

- ここに書いた構造は、**一事業所から見える範囲**のものです。
- 数字はありません。**第 5 節の「数えるもの」は、まだ一度も運用されていません。**
- 制度の層（第 1 節の下の行）について、わたしたちは**提案しかできません。**

**できないことを先に書いたのは、そのためです。**
