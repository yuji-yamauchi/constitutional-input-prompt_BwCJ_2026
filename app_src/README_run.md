# 動かし方（下書き・README の「How to run it」の材料）

Python 3.10 以上だけで動きます。追加のライブラリはありません（`pip install` は不要・`requirements.txt` の中身は注釈 1 行だけです）。ビルドもありません。
二つの小さなサーバーを手元で起動します。どちらも `127.0.0.1` だけで待ち受けます（外からは見えません。`Host` が手元の名でない要求は 421 で断ります）。

**コマンドはすべて、このリポジトリの一番上（`app_src` フォルダが見える場所）で打ちます。**

環境変数の付け方の例（値はご自身の物に）

```
# Windows（PowerShell）
$env:VAULT_PASSPHRASE = "あなたの合言葉"
# Windows（コマンド プロンプト）
set VAULT_PASSPHRASE=あなたの合言葉
# macOS / Linux
export VAULT_PASSPHRASE="あなたの合言葉"
```

## 1. 受け口（参照用）を起動する

受け口は、本人が渡した「写し」を人（メンター）が読んで、人の手で返事を書くための面です。Claude は呼びません。

必要な環境変数（名だけ・値はご自身で決めてください）

| 名 | 意味 |
|---|---|
| `PORT_PASSPHRASE` | 受け口の係のログインの合言葉（16 字以上。短いと「設定が ありません。」になります） |
| `PORT_ID` | 受け口の id（例: 任意の短い英数字） |
| `PORT_NAME` | 受け口の名（画面と控えに出ます。例: 受け口（参照用）） |
| `CIP_PORT_DIR` | 保存の場所（省略時＝ホームの `cip_port_data/`） |
| `CIP_PORT_PORT` | 待ち受けの番号（省略時 8766） |

```
python3 -m app_src.receiver_app.main
```

ブラウザで `http://127.0.0.1:8766/` を開き、合言葉でログインします。

## 2. 器（本人のアプリ）を起動する

| 名 | 意味 |
|---|---|
| `VAULT_PASSPHRASE` | 本人の入口の合言葉（無いと「設定が ありません。」の 1 行だけになります。5 回 続けて違えると 5 分 止まります） |
| `ANTHROPIC_API_KEY` | Claude の鍵。**無ければ Claude を使う機能だけが止まります**（ほかの機能は動きます） |
| `CIP_DEMO_MODE` | `1` にすると、Claude を呼ばずに「記録済みの応答」を返します。画面の上に常時 帯が出ます（記録が手書きの物なら「用意した 物です」、本物の記録なら「録画用に記録した物です」＝下の「5a. 本物の応答を記録する」） |
| `CIP_CLAUDE_MODEL` | Claude のモデル名（省略時の値はコードの定数。ご自身の鍵で使えるモデル名に合わせてください） |
| `CIP_VAULT_DIR` | 器の保存の場所（省略時＝ホームの `cip_vault/`。repo の外に置きます） |
| `CIP_VAULT_PORT` | 待ち受けの番号（省略時 8765） |
| `PORT_BASE_URL` | 受け口の場所（省略時 `http://127.0.0.1:8766`） |
| `CIP_LAW_DIR` | 法令集の置き場（省略時 `app_src/law_corpus`） |

```
python3 -m app_src.vault_app.main
```

ブラウザで `http://127.0.0.1:8765/` を開き、合言葉でログインします。

## 3. 二つをつなぐ

1. 受け口の面で「つなぐ合言葉を 出す」→ 一度だけ使える合言葉が出ます（24 時間・1 回だけ）。
2. 器の「人に わたす」→「つなぐ」に、その合言葉を入れます。
3. 以後、器から渡した写しが受け口に届き、受け口で人が書いた返事は、器で「読み直す」を押したときだけ取りに行きます（入口を通っただけでは取りに行きません）。

## 4. デモ用のダミー書類

`app_src/demo/docs/` の SVG は自作のダミーです（実在の様式・実在の人の情報は含みません）。
写真として取り込むには PNG が要るので、次で書き出します（`app_src/demo/png/` にできます）。

```
python3 -m app_src.tools.unpack_demo
```

## 5a. 本物の応答を記録する（作成者が 1 回だけ）

鍵なしのデモで本物の応答を見せるために、作成者が自分の鍵で 1 回だけ記録を作ります（3 行）。

```
export ANTHROPIC_API_KEY="あなたの鍵"            # Windows は set / $env:
export CIP_CLAUDE_MODEL="使えるモデル名"          # 既定のモデル名で 404 が出たときだけ
python3 -B -m app_src.tools.record_demo           # 呼ぶ前に試すなら --dry-run
```

録画用のシナリオ（鍵なしのデモで、決まった入力に決まった返事が返る物）は `app_src/demo/recorded/listener/<入力の sha256 の先頭 16 字>.json` に手書きで置いてあります（`recorded_from_live: false`。仕様書 v0.9 §3.7 の入力の字をそのとおり打つと返ります）。

入力は `app_src/demo/record_inputs.json`（本人の短い文 3 つ・困っていることと のぞむことの 1 組・ダミー書類 4 枚）。応答は `app_src/demo/recorded/<役>/` に `recorded_from_live: true` で書かれ、`default.json` も本物に置き換わります。
記録には鍵も原本の画像も書きません。終わると、役ごとの件数と「帯＝本物の記録／まだ仮」が出ます。

## 5. 検査

```
python3 -B -m app_src.tests.run_all          # 陰性対照（わざと壊した入力で落ちること）→ 本物 の順に全部
python3 -B -m app_src.tools.scan_words --selftest     # 画面と指示の字の走査（使わない言い方が 0）
python3 -B -m app_src.tools.scan_network --selftest   # 外へ出る通信の部品が 2 つだけ・受け口は 0
python3 -B -m app_src.tools.scan_leaks --selftest   # 鍵・uuid・URL・メールの字が 0
```

## 6. 保存と削除

- 器の中身はすべて `CIP_VAULT_DIR` のフォルダにあります（JSON・Markdown・画像のまま＝開いた形式）。書き出した zip だけは `CIP_VAULT_DIR` の隣の `cip_exports/` に置かれ、「器の中身をけす」で一緒に消えます。v0.3 からは、新しく書くファイルとフォルダを本人だけが読める権限（600／700）で作ります（それより前に作った物はそのままです。気になるときは器を新しく作り直してください）。
- 「きょうの こと」（ゆうべ ねた 時刻・おきた 時刻・あさごはん）は `daily/<日付>.json` に日ごとに 1 つ置かれ、書き出しに入り、「器の中身をけす」で消えます。束には入りません。聞き役へは送られません（画面に「聞き役に 伝える」の切替はありません。チャットの頭の欄から保存するだけです）。
- 「きょうの 気分」（60 問の 答え）は `kibun/<日付>.json` に日ごとに 1 つ（回ごとの並び）置かれ、書き出しに入り、「器の中身をけす」で消えます。束には入りません。聞き役へは送られません。点を付けたり くらべたり しません。
- 「記録の一覧」→「ぜんぶ書き出す」で zip にまとめて手元に置けます。件数は器の中の数と一致します。
- 「器の中身をけす」で全部消せます（控えを残すかどうかを先に選びます）。

## 7. 個人情報について

このリポジトリに個人情報は含まれていません。デモの素材はすべて自作のダミーです。鍵・合言葉の値はリポジトリに置かず、環境変数で渡します。
