# 00_devlog — Daily log

A dated record of what was decided, what went wrong, and how it was corrected. One file per day. Entries are added, never overwritten.

**日本語** — その日に何を決め、何を間違え、どう直したか。日付ごとに 1 ファイル。版は上書きせず足す。
