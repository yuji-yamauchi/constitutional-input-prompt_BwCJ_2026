# 00_devlog — Daily log ／ 開発日報

A dated record of what was decided, what went wrong, and how it was corrected.
One file per day. Entries are added, never overwritten.

その日に何を決め、何を間違え、どう直したか。日付ごとに 1 ファイル。上書きせず足す。

| | |
|---|---|
| **[`en/`](en/)** | English |
| **[`ja/`](ja/)** | 日本語（original ／ 原文） |

> The Japanese is the version these entries were written in; the English is a
> translation of it. Where the two differ, the Japanese is the record.
>
> この日報は日本語で書かれたものです。英語はその訳です。食い違う場合、記録は日本語の側です。
