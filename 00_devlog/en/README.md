# 00_devlog — Daily log

A dated record of what was decided, what went wrong, and how it was corrected.
One file per day. Entries are added, never overwritten — a mistake stays on the
page next to its correction, because a log that only shows the good decisions is
not a record of how the thing was actually built.

The Japanese originals are in [`../ja/`](../ja/).
